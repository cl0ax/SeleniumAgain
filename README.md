# Selenium-Test

A Selenium WebDriver testing project using Firefox and JUnit 5. This project automates browser-based testing with Selenium 3.141.59 and GeckoDriver.

## Quick Start

- **Tests**: Located in `Tests/` directory
- **Source**: Located in `src/` directory
- **WebDriver**: Firefox with GeckoDriver (in `drivers/` folder)
- **Test Framework**: JUnit 5 (Jupiter)

For detailed setup and development instructions, see [CLAUDE.md](CLAUDE.md).
